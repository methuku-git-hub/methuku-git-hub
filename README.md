## Research projects

- **[Nearly linear directed cycles in vertex-transitive digraphs](https://github.com/methuku-git-hub/Nearly-linear-directed-cycles-in-vertex-transitive-digraphs)**
  Joint work with Bowen Li. We prove that for every $\varepsilon>0$ there exists $n_0=n_0(\varepsilon)$ such that every connected vertex-transitive digraph on $n\ge n_0$ vertices contains a directed cycle of length at least $n^{1-\varepsilon}$. Here connectedness refers to the underlying undirected graph. The repository contains a complete Lean formalization of this result (Theorem 1.5) and its proof dependencies.

- **[Independent sets in hypergraphs with no loose triangle](https://github.com/methuku-git-hub/Independent-sets-in-hypergraphs-with-no-loose-triangle)**
  Joint work with Ayush Basu and Abhishek Dhawan. Assuming the stated Li–Postle vertex-coloring bound, we prove that for every integer $r\ge 3$ there exist constants $c_r>0$ and $N_r$ such that every hypergraph on $n\ge N_r$ vertices, with edge sizes between $3$ and $r$ and no loose triangle, contains an independent set of size at least $c_r n^{2/3}(\log\log n)^{1/3}$. The repository formalizes this implication (Theorem 1.3) in Lean.
