## Research projects

- **[Nearly linear directed cycles in vertex-transitive digraphs](https://github.com/methuku-git-hub/Nearly-linear-directed-cycles-in-vertex-transitive-digraphs)**
  Joint work with Bowen Li. Lean formalization of the near-linear directed-cycle theorem, with a manuscript snapshot, proof sources, and verification materials.

- **[Independent sets in hypergraphs with no loose triangle](https://github.com/methuku-git-hub/Independent-sets-in-hypergraphs-with-no-loose-triangle)**
  Joint work with Ayush Basu and Abhishek Dhawan. Lean formalization of Theorem 1.3: assuming the stated Li–Postle vertex-coloring bound, for every fixed $r \ge 3$, every sufficiently large $n$-vertex hypergraph with edge sizes between $3$ and $r$ and no loose triangle contains an independent set of size at least $c_r n^{2/3}(\log\log n)^{1/3}$, where $c_r>0$ depends only on $r$.
